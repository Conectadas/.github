# Conectadas 💜

**Conectadas** es una comunidad creada por y para chicas, diseñada para conectar, compartir y crear experiencias juntas en un ambiente seguro.

Nuestra plataforma permite a las chicas:

* 👯‍♀️ Conocer y conectar con otras chicas.
* 🎉 Encontrar compañía para eventos y planes.
* 🤝 Crear nuevos contactos a través de nuestro directorio.
* 💬 Construir una comunidad basada en confianza y seguridad.

**Chicas para chicas. Conectadas para compartir.**
